# 多机位访谈字幕处理器 - 使用说明

## 🎬 功能特性

### 核心功能
- ✅ **多机位支持**：1-8 个机位同时处理
- ✅ **长视频支持**：访谈、纪录片等大文件
- ✅ **说话人分离**：轻量级算法，无需 PyAnnote
- ✅ **多轨导出**：FCPXML / Premiere XML / SRT
- ✅ **字幕搜索**：关键词快速定位

### 系统要求
- Windows 10/11
- Python 3.8+
- 8GB+ 内存（推荐 16GB）

---

## 🚀 快速开始

### 方法一：一键启动（推荐）

```bash
双击运行：start-multicamera.bat
```

系统会自动：
1. 检查并安装依赖
2. 启动后端服务 (端口 5000)
3. 启动前端服务器 (端口 8080)
4. 打开浏览器

### 方法二：手动启动

```bash
# 终端 1：启动后端
py multi_camera_app_v2.py

# 终端 2：启动前端
py -m http.server 8080

# 浏览器访问
http://localhost:8080/multi_camera_index.html
```

## 📋 使用流程

### 1. 创建项目
- 点击「新建项目」
- 输入项目名称（如：某某访谈-2024）
- 选择机位数量（1-8）

### 2. 上传机位
- 为每个机位上传视频文件
- 支持格式：MP4, MOV, AVI, MKV, MXF
- 等待所有机位上传完成

### 3. 开始处理
- 点击「开始转录处理」
- 系统会自动：
  - 提取音频
  - Whisper 语音识别
  - 说话人分离
  - 匹配机位信息

### 4. 查看字幕
- 切换到「字幕编辑」标签
- 搜索关键词快速定位
- 查看每个字幕的机位和说话人

### 5. 导出工程
- 切换到「导出工程」标签
- 选择目标剪辑软件：
  - **Final Cut Pro**：导出 .fcpxml
  - **Adobe Premiere**：导出 .xml
  - **DaVinci Resolve**：导出 .fcpxml
  - **多轨 SRT**：带机位标记的字幕

## 🔧 技术说明

### 说话人分离
使用轻量级算法实现：
- 提取音频 MFCC 特征
- K-means 聚类区分说话人
- 无需下载大模型
- 适合 2-4 人访谈场景

### Whisper 模型
- 使用本地缓存：`C:\Users\36961\.cache\whisper`
- 默认使用 base 模型
- 支持中文识别

### 导出格式

#### FCPXML（Final Cut Pro）
- 多机位角度同步
- 按说话人分轨字幕
- 时间线可编辑

#### Premiere XML
- 多视频轨道
- 字幕标记
- 兼容 CC 2020+

#### 多轨 SRT
```
1
00:00:01,000 --> 00:00:05,000
[机位 1] SPEAKER_00: 大家好，欢迎...

2
00:00:05,500 --> 00:00:10,000
[机位 2] SPEAKER_01: 谢谢，很高兴...
```

## ⚠️ 注意事项

### 浏览器访问
- 必须使用 `http://localhost:8080`
- **不要**直接双击打开 HTML 文件
- 推荐使用 Chrome 或 Edge

### 视频格式
- 推荐 MP4 (H.264)
- 如果处理失败，尝试用 ffmpeg 转码：
```bash
ffmpeg -i input.mov -c:v libx264 -c:a aac output.mp4
```

### 内存使用
- 长视频处理可能需要较多内存
- 如果内存不足，可以分段处理

## 🔍 故障排除

### 问题：API 未连接
**解决**：
1. 检查后端是否启动
2. 刷新页面
3. 查看 CMD 窗口是否有报错

### 问题：转录失败
**解决**：
1. 检查视频是否可以正常播放
2. 尝试转换为 MP4 格式
3. 检查磁盘空间

### 问题：说话人分离不准确
**解决**：
1. 确保各机位音频清晰
2. 说话人之间有明显停顿
3. 手动调整字幕轨道
