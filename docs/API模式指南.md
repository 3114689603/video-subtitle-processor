# API 模式使用指南

## 快速启动 API 模式

### 方法一：双击启动（推荐）

1. **双击运行** `start-api.bat`
2. 等待显示 "服务地址: http://localhost:5000"
3. **不要关闭** 黑色命令窗口
4. 用浏览器打开 `index.html`
5. 右下角状态显示 "API已连接" 即成功

### 方法二：手动启动

```bash
# 1. 进入项目目录
cd "视频字幕处理器"

# 2. 安装依赖（首次使用）
python -m pip install flask flask-cors

# 3. 启动后端服务
python app.py
```

然后浏览器打开 `index.html`

## 切换模式说明

### 自动切换
- 页面加载时**自动检测** API 是否可用
- 如果检测到 `http://localhost:5000` 可用 → **API模式**
- 如果检测不到 → **离线模式**

### 手动刷新切换
1. 启动 API 服务后
2. 在浏览器中**刷新页面** (F5)
3. 自动切换到 API 模式

## API 端点测试

启动服务后，可以测试以下地址：

- **健康检查**: http://localhost:5000/api/health
- **上传视频**: POST http://localhost:5000/api/upload
- **处理视频**: POST http://localhost:5000/api/process
- **搜索字幕**: POST http://localhost:5000/api/search

## 常见问题

### Q1: 显示 "离线模式" 怎么办？

**检查步骤：**
1. 确认黑色命令窗口（start-api.bat）正在运行
2. 确认没有报错信息
3. 刷新浏览器页面 (F5)

### Q2: 端口被占用怎么办？

修改 `app.py` 最后一行：
```python
# 原来
app.run(host="0.0.0.0", port=5000, debug=True)

# 改为其他端口，如 5001
app.run(host="0.0.0.0", port=5001, debug=True)
```

然后修改 `app.js`：
```javascript
const API_BASE_URL = 'http://localhost:5001/api';
```

### Q3: 如何确认 API 正常工作？

浏览器访问：http://localhost:5000/api/health

应该返回：
```json
{
  "status": "healthy",
  "timestamp": "2024-01-15T10:30:00"
}
```

## 两种模式对比

| 功能 | 离线模式 | API模式 |
|-----|---------|---------|
| 需要后端 | ❌ 不需要 | ✅ 需要启动 |
| 字幕生成 | 模拟数据 | 真实语音转文字 |
| 文件导出 | ✅ 支持 | ✅ 支持 |
| 搜索定位 | ✅ 本地搜索 | ✅ 后端搜索 |
| 适合场景 | 演示/测试 | 正式使用 |

## 推荐工作流

### 快速演示（离线模式）
直接打开 `index.html` → 上传视频 → 查看功能

### 正式使用（API模式）
1. 双击 `start-api.bat` 启动后端

## 关闭服务

- **API 模式**: 在黑色命令窗口按 `Ctrl+C`，然后关闭窗口
- **离线模式**: 直接关闭浏览器即可
