# 视频字幕处理器 - 快速启动指南

## 🚀 最快方式（推荐）

### 1. 双击启动
```
双击运行: start-all.bat
```

然后等待浏览器自动打开，右下角显示 **🟢 API已连接** 即可使用！

---

## 📋 所有启动方式对比

| 方式 | 文件 | 适合人群 | 特点 |
|------|------|---------|------|
| **一键启动** | `start-all.bat` | 所有人 | 最简单，双击即可 |
| **智能启动** | `launcher.py` | 所有人 | 彩色输出，自动重试 |
| **手动启动** | 见下方 | 开发者 | 可控性强 |
| **诊断工具** | `diagnose.bat` | 出问题用 | 检查环境，排查故障 |

---

## 🔧 手动启动（如果一键启动失败）

### 步骤 1: 启动后端 API
```bash
cd Desktop/视频字幕处理器
python app.py
```
保持这个窗口运行！

### 步骤 2: 启动前端服务器（新开一个 CMD 窗口）
```bash
cd Desktop/视频字幕处理器
python -m http.server 8080
```

### 步骤 3: 浏览器访问
```
http://localhost:8080
```

**注意**：不要双击打开 `index.html`，那样会显示 "API未连接"！

---

## ❌ 停止服务

### 方式 1: 一键停止
```
双击运行: stop.bat
```

### 方式 2: 手动关闭
直接关闭弹出的两个 CMD 窗口即可。

---

## 🔍 常见问题排查

### 问题 1: 显示 "API未连接"

**原因**: 直接双击打开了 HTML 文件

**解决**: 必须通过 http://localhost:8080 访问

```
❌ 错误: file:///C:/.../index.html
✅ 正确: http://localhost:8080
```

---

### 问题 2: 端口被占用

**现象**: 提示 "Port 5000 is in use" 或 "Port 8080 is in use"

**解决**:
1. 运行 `stop.bat` 关闭旧服务
2. 或重启电脑
3. 或修改端口（见下方高级设置）

---

### 问题 3: Python 未安装

**解决**:
1. 访问 https://www.python.org/downloads/
2. 下载 Python 3.8+
3. 安装时勾选 "Add Python to PATH"

---

### 问题 4: 缺少依赖

**现象**: 提示 "No module named 'flask'"

**解决**:
```bash
python -m pip install flask flask-cors
```

## 🛠️ 高级设置

### 修改端口（如果 5000/8080 被占用）

**修改后端端口** (`app.py`):
```python
# 最后一行改为:
app.run(host="0.0.0.0", port=5001, debug=True)
```

**修改前端端口** (`start-all.bat`):
```batch
# 改为其他端口，如 8081
python -m http.server 8081
```

**修改 API 地址** (`app.js`):
```javascript
// 改为对应的后端端口
const API_BASE_URL = 'http://localhost:5001/api';
```

## ✅ 验证是否成功

### 检查 1: 后端启动成功
CMD 窗口显示：
```
Mode: Whisper
URL: http://localhost:5000
 * Running on http://127.0.0.1:5000
```

### 检查 2: 前端连接成功
浏览器右下角显示：
- 🟢 **API已连接** ← 成功！
- 🟡 **离线模式** ← 失败了，看上方排查

### 检查 3: 测试 API
浏览器访问：http://localhost:5000/api/health
应该返回 JSON 数据。
