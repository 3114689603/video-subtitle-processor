# 视频字幕处理器 - 统一版

一个专业的视频字幕处理工具，**单视频**和**多机位**功能整合在一个界面中。

## 🎬 功能特点

- ✅ **单视频模式** - 快速处理单个视频，自动生成字幕
- ✅ **多机位模式** - 支持访谈多镜头同步处理
- ✅ **说话人分离** - 自动识别不同说话人
- ✅ **多格式导出** - SRT、JSON、FCPXML、Premiere XML
- ✅ **统一界面** - 一个页面切换两种模式，无需重启

## 🚀 快速开始

### 一键启动

```bash
双击运行：启动程序.bat
```

选择 `1` 启动统一版（推荐）

### 访问地址

- 页面地址: http://localhost:8080
- API地址: http://localhost:5000/api

## 📋 使用说明

### 单视频模式

1. 点击顶部「单视频」按钮
2. 上传视频文件
3. 等待自动识别完成
4. 查看、搜索字幕
5. 导出 SRT/FCPXML

**适用场景**：演讲、教程、会议记录、短视频

### 多机位模式

1. 点击顶部「多机位」按钮
2. 创建项目，设置机位数量
3. 为每个机位上传视频
4. 点击「开始处理」
5. 查看多机位时间线
6. 导出多轨工程文件

**适用场景**：人物访谈、圆桌讨论、对话节目

```bash
pip install flask flask-cors openai-whisper librosa scikit-learn soundfile
```

## ⚠️ 重要提示

1. **必须使用浏览器访问**：`http://localhost:8080`
2. **不要直接双击打开 HTML 文件**
3. **启动后会弹出 2 个 CMD 窗口**，请勿关闭
4. Whisper 模型缓存在：`C:\Users\36961\.cache\whisper`

## 🔄 模式对比

| 功能 | 单视频模式 | 多机位模式 |
|------|-----------|-----------|
| 视频数量 | 1 个 | 2-8 个 |
| 处理速度 | 快 | 较慢 |
| 说话人分离 | ✅ | ✅ |
| FCPXML导出 | ✅ | ✅ (多机位) |
| Premiere导出 | ❌ | ✅ |
| 适用场景 | 单人录制 | 对话访谈 |

